A student research website developed for IT 3203.

About the student

My name is Evan Clark, and I am studying cybersecurity at Kennesaw State University. I am interested in how technology works and how security decisions affect everyday users.

This website builds on my Assignment #1 research presentation about the evolution of web browsers.

Project details

  • Course: IT 3203
  • Term: Fall 2026
  • Topic: Web browsers

Project purpose

The goal is to explain browser history, the technology that turns code into webpages, and important ideas in browser security and privacy. The website also demonstrates HTML page structure, navigation, tables, images, and responsive CSS layout.

Future milestones can expand the research and add more interactive features.
