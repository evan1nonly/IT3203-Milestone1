SECTION 01 • HISTORY

The Evolution of Web Browsers

Browser competition helped transform the web from a document viewer into a platform for applications.

A brief timeline

1990

WorldWideWeb

Tim Berners-Lee created the first browser and editor at CERN.

1993

Mosaic

Mosaic helped make graphical browsing more approachable by displaying text and images together.

1995

Internet Explorer

Microsoft entered the browser competition that shaped desktop browsing.

2004

Firefox

Mozilla offered a major open-source alternative with extensions and tabbed browsing.

2008

Google Chrome

Chrome emphasized speed, sandboxing, and separate processes.

2015 onward

Mobile-first browsing

Safari and Chromium-based products helped shape the phone-first web.

The browser wars

Netscape Navigator became popular in the 1990s. Microsoft responded with Internet Explorer, which became dominant on desktop computers.

Competition encouraged innovation, but browser-specific features also caused compatibility problems. Shared web standards help developers build sites that work across different browsers.

Modern engine families

  • Blink: Chrome, Edge, and other Chromium-based browsers
  • WebKit: Safari
  • Gecko: Firefox
