SECTION 03 • KEY CONCEPTS

Seven Key Browser Concepts

These seven ideas help explain how browsers display pages, run code, and protect users.

01

Web browser

Software that retrieves, interprets, and displays web resources.

02

Rendering engine

The component that turns document structure and style rules into visible content.

03

Document Object Model (DOM)

A tree of objects representing the HTML document that scripts can inspect and change.

04

CSS Object Model (CSSOM)

The browser’s representation of CSS rules and how styles apply.

05

JavaScript engine

The component that executes JavaScript to support interactive behavior.

06

Sandboxing

A security technique that restricts what untrusted page code can access.

07

HTTPS and TLS

Technologies that authenticate a website connection and encrypt data in transit.

Why these concepts matter

Understanding the DOM, CSSOM, and rendering process helps developers explain how HTML and CSS become a page. Understanding HTTPS and sandboxing shows why modern browsers need security features in addition to speed.
